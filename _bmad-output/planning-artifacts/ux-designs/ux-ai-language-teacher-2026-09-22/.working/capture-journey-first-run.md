# Capture — Journey: First run (Денис)

## Protagonist

- Денис — первый запуск desktop-приложения (личность как в PRD Target User)

## Flow — First run → calendar home (resolved)

1. Денис впервые открывает приложение.
2. Приветствие: как обращаться + возраст → «Далее».
3. Цель изучения + желаемый результат → «Далее».
4. Интересы / акцент → длительность урока → расписание (Outlook week slots) → «Далее».
5. Consent: микрофон/запись голоса; Telegram; AI disclaimer; Privacy/PII → «Далее».
   - Возраст уже на шаге 2 — на consent не дублируется как отдельный блок.
6. Брифинг placement: что за тест, сколько времени, как оценивается, на что повлияет → «Далее».
7. Письменное тестирование → «Далее» или истечение таймера этапа.
8. Listening-тест: пояснение → «Прослушать» → аудио → вопросы → «Далее».
9. Speaking-тест: диалог с приложением → «Далее».
10. Экран с анимацией: «создаём план обучения».
11. **Climax:** главный экран — календарь; в боковой панели — краткое пояснение, как начать первый урок.
    - Без отдельного Living-plan review и без обязательного «Начать урок» как climax.

## Overrides vs prior onboarding capture

- Wizard order replaced: name/age → goals/outcomes → interests/emphasis → duration → schedule (Outlook) → consent → placement briefing → written → listening → speaking → plan animation → calendar tip.
- Placement: multi-stage + briefing (not single short test screen only).
- Consent screen added in onboarding (mic, Telegram, AI disclaimer, Privacy/PII).

## Failure / edges (open)

- (не narrated) выход mid-wizard, отказ consent, mic deny, timeout speaking

- Closed for coaching (Journey 1)
