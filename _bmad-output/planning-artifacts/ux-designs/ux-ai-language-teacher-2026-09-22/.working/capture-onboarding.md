# Capture — onboarding

## Form

- Step-by-step wizard (one screen = one step)

## Placement

- Multi-stage with briefing screen, then: written → listening → speaking
- Not a single short screen only

## After placement

- Plan-creation animation → land on calendar home
- No dedicated Living-plan review step in onboarding wizard
- Side panel on calendar: tip how to start first lesson (Journey climax)

## Schedule step

- Outlook-like week slots (after interests/emphasis + duration, before consent)

## Consent (onboarding)

- Mic / voice recording
- Telegram
- AI disclaimer
- Privacy / PII
- Age collected on name step — not repeated as consent block

## Living plan access (post-onboarding)

- Both: app nav/header AND calendar side panel

## Wizard order (override)

1. Name + age (greeting)
2. Goals / desired outcomes
3. Interests / emphasis
4. Duration
5. Schedule (Outlook-like slots)
6. Consent
7. Placement briefing
8. Written test
9. Listening test
10. Speaking test
11. Create Living plan (animation) → calendar home + first-lesson tip in side panel
