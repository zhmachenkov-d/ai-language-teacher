# Capture — Journey: Typical lesson (Денис)

## Protagonist

- Денис — обычная учебная сессия по расписанию

## Flow — Reminder → lesson → history → calendar

1. За 15 минут: Telegram-напоминание — через 15 мин урок по теме …
2. В момент старта: Telegram — «пришло время позаниматься», ждёт урок по теме …
3. Денис открывает desktop-приложение.
4. **Gate (только если есть урок «сейчас» / due):** «Начать урок» | «Перейти в календарь».
5. «Начать урок» → экран урока.
6. Приветствие + краткий рассказ о плане → урок по Lesson template.
7. План выполнен → прощание + дата/время следующего запланированного урока.
8. **Climax:** урок помечен пройденным → экран переходит в режим истории (read-only) по этому уроку.
9. Просмотр истории **или** «Закончить» → календарь.

## Branch — выбрал «в календарь» при due

- Календарь + боковая панель как раньше: превью (тема + краткий план) + CTA «Начать урок».

## Gate scope

- Only when a lesson is due / «сейчас» — not on every app open just because next is scheduled.
