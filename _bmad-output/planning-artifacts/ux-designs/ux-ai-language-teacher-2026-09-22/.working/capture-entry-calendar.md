# Capture — entry calendar

- First screen: calendar with lesson marks
- States: completed / scheduled
- Next scheduled: bold + background color
- Missed: color + exclamation icon

## View grain
- Both week and month; default week

## Click behavior
- Completed → lesson history
- Next / missed → topic + short plan description + button «Начать урок»

## Preview chrome
- Side panel beside calendar

## Future scheduled (not next / not missed)
- Same preview (topic + short plan), no «Начать урок»

## Default panel (no selection)
- Hint: «выберите урок для просмотра краткой информации или истории»

## Visual/IA reference
- Calendar similar to Outlook 365 (layout/interaction pattern)

## Today
- Today’s day must be visually marked for time orientation (separate from next/missed lesson states)

## Timed grid
- Lessons placed on hour grid like Outlook (timed events)

## Today treatment
- Like Outlook: circled/pill date number; current-time line on grid when today visible
