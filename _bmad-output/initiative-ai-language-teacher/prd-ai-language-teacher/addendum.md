# Addendum — PRD AI Language Teacher

## Delivery (user-stated)

- Between-lesson **Micro-lessons** in v1 are delivered via **Telegram**.
- **Lesson reminders** in v1 are delivered via **Telegram** (not in-app-only).
- Other delivery channels are later expansion, not v1.

## Deferred product scope

- Certificate-oriented track — after v1 oral/teaching loop (**intentional override** of product brief v1-in scope; revisit when oral loop works)
- Multi-user web, multi-language targets — Vision horizon

## Lesson template timing bands (from product brief addendum)

Teacher selects layout from performance and error patterns.

- **Study-heavy:** warm-up/review 5–10 → new material 10–15 → new words 10–15 → checks 10–15 → error review 10–15
- **Oral:** warm-up/review 5–10 → dialogue 10–15 → listening 10–15 → error review 10–15
- **Transfer / weak-spot:** recurring-error warm-up 5–10 → i+1 listening 8–12 → new-scenario role-play 12–15 → shadowing/re-say 5–8 → capture to review 2–5

## Stack (from product brief — architecture later)

- Desktop: Electron + Vue; backend Python (possibly LangGraph)
- LLM: remote/API with local keys OK; not fully offline in v1
