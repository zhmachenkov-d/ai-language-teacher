# Desktop teacher foundation

## Description

Learner can launch the Electron desktop app with the Python teacher service running in the background, configure documented Settings shells, and see branded calendar-home chrome in a ready/empty state — without stopping reminder delivery when the window closes.

## Outcome

Learner can launch the Electron desktop app with the Python teacher service running in the background, configure documented Settings shells, and see branded calendar-home chrome in a ready/empty state — without stopping reminder delivery when the window closes.
