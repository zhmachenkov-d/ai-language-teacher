# Lesson templates — timing bands (v1)

Teacher selects layout from performance and error patterns (CAP-4). Times in minutes.

## Study-heavy

| Phase            | Minutes |
| ---------------- | ------- |
| Warm-up / review | 5–10    |
| New material     | 10–15   |
| New words        | 10–15   |
| Checks           | 10–15   |
| Error review     | 10–15   |

## Oral

| Phase            | Minutes |
| ---------------- | ------- |
| Warm-up / review | 5–10    |
| Dialogue         | 10–15   |
| Listening        | 10–15   |
| Error review     | 10–15   |

## Transfer / weak-spot

| Phase                   | Minutes |
| ----------------------- | ------- |
| Recurring-error warm-up | 5–10    |
| i+1 listening           | 8–12    |
| New-scenario role-play  | 12–15   |
| Shadowing / re-say      | 5–8     |
| Capture to review       | 2–5     |
