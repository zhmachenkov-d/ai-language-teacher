# Capture — Journey: Incomplete resume «Не завершен» (Денис)

## Protagonist

- Денис — урок прерван внешним событием, затем resume

## Flow (resolved)

1. Mid-lesson внешнее прерывание (звонок); нет возврата >~15 мин.
2. Приложение автоматически ставит урок на паузу (= явная «Пауза», только auto) → статус «Не завершен».
3. При повторном открытии приложения, пока есть «Не завершен»: **gate «Продолжить» | «В календарь»** (как due-gate).
4. Или из календаря: выбор урока → боковая панель → «Продолжить».
5. Экран урока: выполненные задания видны; старт с незаконченного задания.
6. **Climax:** доводит оставшееся → нормальное завершение → переход в историю (как Journey 2).

## Auto-close rule

- Equivalent to header «Пауза», triggered automatically after prolonged absence (~15 min in narrative).

## Status

- Closed for coaching (Journey 4)
