AI Language Teacher

Architecture overview for investors · September 2026

A personal desktop teacher that closes the loop learners actually need: plan → voice lesson → feedback → remind → adapt — without betting on a proprietary model.

The bet

Differentiation is teacher-like continuity, not another chat box. v1 targets one learner (English with Russian explanations) on a local desktop, with speaking and listening as first-class work — not text drills with a microphone bolted on.

Place & plan→ Voice lesson→ Errors & progress→ Telegram cadence→ Replan

Why this architecture

Local teacher service

The “teacher” keeps running in the background. Closing the window does not kill reminders or between-lesson practice.

Privacy by design

Learner data and API keys stay on the machine. Personal identifiers are kept out of model prompts. Voice is local-first, with optional cloud only when explicitly enabled.

Swappable intelligence

Hexagonal core: pedagogy owns the plan and the lesson. LLM, speech, and Telegram plug in as adapters — so vendors can change without rewriting the teacher.

One source of truth

Desktop lessons and Telegram micro-lessons write the same progress store. The living plan is revised by the teacher, not by competing UIs.

What ships in v1

  • Desktop app (Electron + Vue) as a thin client to a Python teacher service
  • Adaptive lesson templates with resume if a session is interrupted
  • Telegram for lesson reminders and short vocabulary micro-lessons
  • Remote LLM with locally stored keys (fully offline model is out of scope)

Horizon (not v1)

Multi-language open source and an optional web surface later. The data model already carries target and explanation languages so expansion does not require a rewrite.

Risk posture

  • Model risk: low moat dependency — quality comes from placement, error memory, and plan revision.
  • Voice quality: local-first with an explicit optional cloud fallback behind one interface.
  • Delivery risk: focused personal product first; multi-user web deliberately deferred.
